# Local font assets

These unmodified font files are distributed under the SIL Open Font License 1.1.
The family-specific OFL files in this directory contain their copyright notices.

- `libre-baskerville.ttf`: Libre Baskerville variable weight, page titles
  https://github.com/google/fonts/tree/main/ofl/librebaskerville
- `ibm-plex-sans.ttf`: IBM Plex Sans variable width/weight, navigation and subheadings
  https://github.com/google/fonts/tree/main/ofl/ibmplexsans
- `source-sans-3.ttf`: Source Sans 3 variable weight, body text and tables
  https://github.com/google/fonts/tree/main/ofl/sourcesans3

Downloaded from Google Fonts' official repository on 2026-11-08.
The UI serves these files locally; it makes no external font requests.
